# PRD：注入头带发出方会话名

## 问题

入站注入头是 `[collab:ses_e176…2HXy][reply:t_mwmj8xw_089v]`——只有截断 id，读的人得反查是谁发的。

## 需求

- **R1 格式**：注入头改为 **名称在前**：
  `[<发出方会话标题>][collab:ses_…][<kind>:<threadID>]`
  - 名称截断 **20 字**（超出 `…`）；
  - `[collab:ses_…]` 与 `[kind:threadID]` 位置/格式**不变**（现有正则与机读不受影响）；
  - 标题取不到（宿主不可读/无标题）→ 退化为现状（只去掉名称段）。
- **R2 缓存**：按 sid 缓存标题（10 分钟），避免每轮注入都打宿主；改名最多滞后 10 分钟。
- **R3 作用域**：只改**入站注入头**（`request` / `reply` / `note` / `steer` 同一套）；`collab_list` / `status` / 看板不动。
- **R4 不改变语义**：注入内容、去重、预算、protected 规则全不变；只多一段可读前缀。

## 验收

- [ ] 四类 kind 的注入头都变成 `[标题][collab:ses_…][kind:t_…]`；
- [ ] 标题 >20 字 → 截断 + `…`；取不到 → 与旧格式逐字一致；
- [ ] 同一 sid 连续两轮注入：宿主只查一次（假宿主计数）；
- [ ] 现有解析（`[collab:ses_…]` 正则、threadID 提取）不受影响，既有断言全绿；
- [ ] 回归全绿（基线以开工时为准）；工具数仍 22。

## 非目标

- 不改出站正文/协议头；
- 不在看板/列表里重复展示名称。
