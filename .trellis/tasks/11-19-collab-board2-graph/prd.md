# PRD：三级关系图

## 需求

- **R1 派生**：`src/core/graph.ts` 纯函数 `buildGraph(snapshot, { level, workspace?, session? })`：
  - L0 全局（无选中）：工作区为节点；跨工作区交接为边（带计数）；
  - L1 工作区：该区会话为节点 + 指向其它工作区的虚线边（不展开对方）；
  - L2 会话：以它为中心的直接关系（`origin → from → claimBy`、`↳ spawned`、`parent/child`），±1 跳、≤8 节点。
  - 边类型：`handoff`（实线）/ `origin`（虚线）/ `spawn`（点线）/ `subagent`（点线）。
- **R2 GUI 渲染**：详情栏顶部小图（SVG，无依赖），节点可点击选中（联动左列表与 items）、节点 `▸/▾` 折叠一跳邻居（仅本窗口内存）、悬停高亮相邻边；超出节点显示 `+N`。
- **R3 TUI 渲染**：等宽文本树（`ses_A ─交接─▶ ses_B`，`↳ spawned`），随级别切换；宽度不足截断并给 `…`。
- **R4 确定性**：同一快照两次渲染**字节一致**（节点/边排序稳定）。
- **R5 只读**：不写任何文件、不投递。

## 验收

- [ ] L0/L1/L2 三份构造快照 → 节点、边、方向、类型正确
- [ ] 节点上限与 `+N` 生效；排序稳定（两次渲染一致）
- [ ] GUI：点节点 → 选中联动；折叠/展开一跳；悬停高亮
- [ ] TUI：文本树含 `▶`/`↳`；窄宽度截断不崩
- [ ] 只读：目录 hash 不变
- [ ] 回归全绿；工具数仍 22
