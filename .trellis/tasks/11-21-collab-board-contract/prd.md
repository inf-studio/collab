# 看板显示会话契约

## 问题

契约数据（主线 / 进度 / 待办 / 漂移）已经在 `collab-contract/<sid>.json` 里，但看板看不到：
人只能靠注入头判断，或者翻会话。实测痛点：排钟会话 10.8 小时无主线推进，看板上**没有任何可见信号**。

## 需求

- **R1 快照**：`snapshot` 为每个会话增加**可选** `contract` 字段（mission/progress/todos/drift），来源只读 `collab-contract/<sid>.json`；缺失或损坏时省略该字段，不抛。
- **R2 列表徽标**（GUI 与 TUI 共用派生）：1 字符 + ≤3 位数字，插在第二行末尾，**不新增行**。
  - 优先级：`drift → ◇ 红` ＞ `suspended/drifted>0 → ◐ 琥珀` ＞ `open/blocked>0 → ◑ 蓝 + 数量` ＞ 正常 `● 灰` ＞ 无契约不显示。
- **R3 详情区**（GUI 右侧 + TUI 详情）固定顺序：主线 / 边界 / 进度 / 待办 / 漂移；缺项隐藏；无契约时整块不渲染。
- **R4 只读**：不得新增任何写动作或 RPC。
- **R5 兼容**：无契约会话、旧快照、远端缺字段时，输出与 **0.9.6 逐字节一致**。

## 验收

- [ ] 有契约：列表出现正确徽标（三种优先级各一例），详情五项按序；
- [ ] 无契约：列表与详情与 0.9.6 逐字节一致，且不创建契约文件；
- [ ] `≤640px` 单栏：徽标不换行、详情可读；
- [ ] TUI 详情行含主线/进度/todo/drift，超宽截断不换行；
- [ ] 契约文件损坏：省略字段 + 一条日志，UI 不崩；
- [ ] 回归全绿；工具数仍 **28**（本任务不新增工具）。
