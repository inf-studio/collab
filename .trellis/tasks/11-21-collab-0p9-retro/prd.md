0.9.x 七个版本（0.9.0–0.9.6）的取舍、被复核打回的点、以及四条遗留，目前只存在于对话与 commit message 里：

## 需求

- **R1** `docs/issues/feat-collab-protocol-v2.md`
  - 每个版本：解决什么 → 关键取舍 → 复核打回的点 → 遗留；
  - 证据：1752 测试、28 工具、实机 rebuild checksum、0.9.6 发布 CI 号；
  - 一节「六项指标」：基线与当前口径（含「回放是合成数据」的标注）。
- **R2** `docs/issues/bugs-rebuild-drops-metrics.md`
  - 现象（`rebuild` 后 `metrics` 清零）/ 复现命令 / 根因 / 修法（指向本批 ①）/ 回滚；
  - 明确「只重算日志覆盖范围，不伪造安装前数据」。
- **R3** `docs/issues/upstream-opencode-64788.md`
  - 上游 issue 链接、现象、我们的绕过（本机安装 + 按会话取 server client）、解除条件。
- **R4** 三份都用本仓 `docs/issues/` 既有格式；每节含「现象 / 证据 / 影响 / 结论或修法」，**不得有占位空段**。

- [ ] 三份文件存在且章节完整，无 `TBD` / `待补`；
