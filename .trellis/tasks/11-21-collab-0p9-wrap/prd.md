# PRD：0.9.x 复盘、看板契约与收尾

## 1. 背景

0.9.0–0.9.6 七个版本已发布（`v0.9.6` CI `44749474730` success），父任务 `11-20-collab-session-contract` 已归档。
当前：Linux `collab:v0.9.6` 生效；mac 配置已切 0.9.6 但**未重启 Desktop**。

遗留四件：

| # | 遗留 | 影响 |
|---|---|---|
| L1 | `collab_index rebuild` 会清空 `metrics` 日计数 | 「永久保留」策略下历史指标不可追溯 |
| L2 | 回放数字（p50 410s / 5.11×）是**合成数据** | 不能当线上实测宣传 |
| L3 | 看板未展示契约（mission / progress / todo / drift 已在 contract 里） | 人看不出「哪条会话要漂了」 |
| L4 | 上游 `anomalyco/opencode#64788`（Desktop 只加载本机 sidecar 的 GUI 插件）未闭环 | 跨机 GUI 仍不可用，已有本机安装绕过 |

## 2. 目标

- **G1** 把 0.9.x 的设计取舍与教训固化成可查文档（3 份，按主题分）。
- **G2** 让「会话主线 / 进度 / 待办 / 漂移」在**列表徽标 + 详情**可见（GUI 与 TUI）。
- **G3** 收尾：`rebuild` 不再丢指标；mac 与 24h 数据可验证。

## 3. 交付与顺序（固定 3 → 2 → 1）

| 序 | 子任务 | 交付 |
|---|---|---|
| **3** | `collab-0p9-retro` | `docs/issues/feat-collab-protocol-v2.md`、`docs/issues/bugs-rebuild-drops-metrics.md`、上游跟进记录 |
| **2** | `collab-board-contract` | GUI 列表徽标 + 右侧详情；TUI 详情；无契约回落 |
| **1** | `collab-0p9-close` | `rebuild` 重算 metrics；mac 重启验证清单；24h 指标对比表 |

顺序理由：先固化认知（低风险、可评审），再改可见层，最后做数据与机器验证（依赖前两步产物）。

## 4. 非目标

- 不做跨机同步（DB 与账本仍本机）。
- 不改变 0.9.x 既有 28 个工具的任何输出契约。
- **不伪造历史指标**：重算只覆盖消息日志已有的时间范围（当前 `messages` 仅安装后少量），文档必须写明。
- 不自动调参（窗口、阈值、闸门档位）——只展示数据。

## 5. 约束

- 文档遵循本仓 `docs/issues/` 现有格式；单一真源在本仓。
- 看板仍是**只读**：徽标/详情不得出现写动作。
- 徽标不得改变「两行」列表布局；`≤640px` 单栏必须仍可读。
- 快照新增字段必须**可选**：旧版/远端无该字段时输出与 0.9.6 逐字节一致。
- 24h 对比只做展示，不自动修改任何配置。

## 6. 验收（跨子任务）

- [ ] 3 份文档齐全，每份含「现象 / 证据（命令或数字）/ 影响 / 修法或结论」，无占位空段。
- [ ] 有契约时：GUI 列表出现徽标、右侧详情含主线/进度/todo/drift；TUI 详情同样可见。
- [ ] 无契约时：列表与详情输出与 0.9.6 **逐字节一致**，且不创建契约文件。
- [ ] `rebuild` 前后：同一时间范围内 `metrics` 逐日字段一致（不再清零）。
- [ ] mac 安装确认（重启后 `collab:active:v0.9.6`）+ 24h 对比表 ≥3 项指标。
- [ ] 全量回归绿；工具数仍 **28**（本批不新增工具）。

## 7. 风险

| 风险 | 处理 |
|---|---|
| 看板徽标破坏两行布局/单栏 | 断点测试 + 变异（徽标多一行 → 断言红） |
| 快照加字段导致旧客户端报错 | 字段可选 + 旧快照夹具逐字节对比 |
| metrics 重算口径与线上不一致 | 重算用与写入同一聚合函数；文档写明覆盖范围 |
| 24h 数据样本太少 | 只报数不下结论；不足 24h 时标「不足」 |
