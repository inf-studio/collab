# PRD：看板主从布局

## 需求

- **R1 GUI 分栏**：面板内左右两栏——左列表（现有工作区 → 会话树，窄、可滚）、右详情（宽）；
  分栏宽度用 CSS grid（左 300–340px，右自适应），窄窗口（≤640px，`max-width:640px`）自动回落单栏：选中会话后详情替换列表，给「返回列表」。
- **R2 右详情结构**：自上而下 ① 会话头（标题 / agent / 完整 sid / 徽标）；② **关系图槽位**（~200px，可折叠；graph 子任务未落地时渲染空占位、不塌陷）；③ 动作行（layout 阶段先留空，actions 子任务填）；④ items（锁 / 交接 / 队列 / `↳` 拉起的会话）。
- **R3 选择状态**：单选；`createSignal<string | null>`（仅组件内存）；**2s 轮询替换快照不得重置选择**；
  选中的会话从**活跃与已归档都消失**时自动清空并提示「该会话已不在快照中」。
  被归档 ≠ 消失：归档会话仍在快照里，仍可选中，详情继续显示并带 `[archived]`（否则从「已归档」段选中会被立刻清掉）。
- **R4 TUI**：树保持现状；`j/k` 选中行时，在树下方追加 3–5 行该会话详情（锁/交接/队列/拉起），`esc` 清除选中。
- **R5 只读**：本子任务不引入任何写路径（动作在 actions 子任务）。

## 验收

- [ ] 构造快照：左列表渲染工作区与会话；点某会话 → 右详情显示其头部与 items；左列表高亮同步
- [ ] 选中后发生一次快照替换（计数证明）→ 选择仍在、详情仍对应
- [ ] 选中会话从快照（活跃 + 已归档）消失 → 选择清空、显示「该会话已不在快照中」；
      仅被归档时选择保留并标 `[archived]`
- [ ] 窄窗口回落单栏 + 返回列表可用
- [ ] TUI：`j/k` 后出现 3–5 行详情；`esc` 清除；既有树断言不变
- [ ] 回归全绿；无新增写路径（grep + 假 ctx）
