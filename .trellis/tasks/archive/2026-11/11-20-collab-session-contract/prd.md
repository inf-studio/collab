# PRD：会话契约与协作根治（0.9.x）

## 1. 背景（实测证据）

对 `ses_edc3c78edffeoH5pvKHZie4Mw5`（issues 实施）与 `ses_e17699cf8ffeHDNLVrKcM62HXy`（排钟专题）两会话的 624 条跨会话消息、24 条 handoff 记录做全量盘点（2026-11-19 07:34 → 11-20 01:04）。

| 指标 | 实测 |
|---|---|
| 跨会话消息 | 624 条 / 807 KB / 17.5h（A→B 310，B→A 314） |
| 人类真实输入 | 排钟 **6 / 323** 轮（1.9%）；issues **13 / 395** 轮（3.3%） |
| 空转消息（无新推送/同上） | 101 条（16%） |
| 撤回/更正 | 117 条（19%）：环境干扰 39 / 工具误用 33 / 探针假象 26 / 口径不同 25 |
| 含「你读的是旧快照/落后」 | 275 条 |
| 含「我这边/你那边/当前状态」镜像 | 431 条（69%） |
| 同事实重复确认 | 一个事实 67 条 / 85 KB / 21 分钟（00:44–01:05），双方自述"第四次/第五次同步" |
| 消息间隔 | p10 6.6s / p50 20s / p90 90s；最长连续 151 条（间隔<2min） |
| 单小时峰值 | 12:00 → 209 KB（≈10 万 tokens） |
| compaction | 两会话各 2 次，均落在最忙时段（12:02 / 00:46） |
| 决策留痕 | **0**（24 条 handoff 的 `decisions[]` 全空，`collab_decisions` 从未使用） |
| 两条最大 thread | 418 / 140 条，**均无 handoff 记录**（纯 thread，无 state / owner / 闭环） |
| 主线漂移 | 排钟 13:00→00:52 **10.8 小时零主线推进**，系统零提醒；最终人类 766 字手工重申主线 + 摘待办 |
| 独立复核 vs 互相转述 | 38 vs 241 |

## 2. 问题定义（根因）

```
① 会话无自我模型   → 我是谁/做什么/不做什么/做到哪/欠谁什么，只存在于对话内容
② 协作靠对话传状态 → 消息塞状态快照，无版本、无账本；消息排队 → 过期快照当现状
③ 唤醒无义务       → idle 不需交待，wake 只需回一条 → 主线永远排在"最新那条"之后
```

三层叠加：上下文稀释（1:53）+ compaction 抹除 + 单条唤醒优先 → **「忘了主线」是必然**。

### 已识别子问题

| 层 | 子问题 |
|---|---|
| 传输 | 过期快照无版本；20 秒 IM 节奏；全量镜像放大；无批量 |
| 语义 | 结论先发后验（撤回 19%）；口径漂移 126 条；撤销无传播（74 条返工）；转述多于独立复核 |
| 任务 | 决策无载体；待办无账本；主线无锚；主线完结无占位 |
| 人类 | 人类被降级为路由器（08:17「帮我转交给 collab 专题」）；重复建任务；"停"靠自声明 |

## 3. 目标

- **G1** 每次请求都能读到：`mission`（我是谁/边界）、`progress`（做到哪）、`todos`（欠什么/挂起）、`facts`（事实是什么）。
- **G2** 越界协作默认被拦（不是劝）。
- **G3** 进度只能由**证据**推进（commit / 测试输出 / 决策 id）。
- **G4** 六个指标可量化，每个版本必须报数：

| 指标 | 基线 | 目标 |
|---|---|---|
| 消息 : 事实 | 67 : 1 | ≤ 5 : 1 |
| 撤回率 | 19% | ≤ 5% |
| 同事实重复确认 | 5 轮 | ≤ 1 轮 |
| 空转率 | 16% | ≤ 2% |
| 消息间隔 p50 | 20s | ≥ 2min |
| 主线漂移 | 10.8h 无提醒 | ≤ 10min 触发提醒 |

## 4. 范围（7 个可独立验收的子任务）

| 版本 | 子任务 | 交付 |
|---|---|---|
| 0.9.0 | `collab-store` | `messages.jsonl` 信封 + `collab.db` 可重建投影 + rebuild + 看板改读索引；零语义改动 |
| 0.9.1 | `collab-contract` | 契约五面持久化 + `[mission]/[progress]/[todo]/[drift]` 每轮注入（四段，不写 injected[]） |
| 0.9.2 | `collab-gate` | 接单前模型表态 `scopeCheck{inScope,reason}` + audit；溢出**只提醒不拦**；零关键词/零额外模型调用 |
| 0.9.3 | `collab-drift` | `[drift]` 三选一；挂起 `wake_when` 必填 + 24h 转 drifted；主线完结核验 next-up |
| 0.9.4 | `collab-facts` | 事实账本 + 证据等级强制 + `settle`/`invalidate` + stale 只回增量 |
| 0.9.5 | `collab-decide` | 决策载具（thread 可用）+ owner 独占关闭 + 同问去重 + open ≤ 3 + 角色四元组 |
| 0.9.6 | `collab-pacing` | 非紧急 **2min** 窗口批量投递 + escalate/blocked 直通 + 无增量不发 |

依赖：0.9.0 → 0.9.1 有硬依赖（注入要读索引）；0.9.4 依赖 0.9.0（facts 表）；0.9.2/0.9.3 依赖 0.9.1（契约存在才谈越界与漂移）。

## 5. 非目标

- 不替换 Trellis 任务体系；契约读 `task.py current`，不另建一套。
- 不做跨机 DB 同步（`~/.config/opencode` 仍本地）。
- 不拦截 bash 层跨仓写（插件无该权限）；边界强制只覆盖**协作层**（accept/broadcast/reply/handoff）。
- 不改变 protected 会话语义与 `BUILTIN_PROTECT`。
- 不删除任何会话；归档仍可逆。

## 6. 约束（决策结论，D1–D21）

| # | 决策 |
|---|---|
| D1 | 父任务 + 7 子任务 |
| D2 | 旧消息无 `basedOn` → 按 `fresh` 处理，注入标 `[基线未知]` |
| D3 | 批量窗口 **2min**（用户选定），escalate/blocked 直通 |
| D4 | 事实账本作用域 = 工作区级共享 |
| D5 | 证据等级强制（未标注 → `[未标注]`，对方可要求补） |
| D6 | `invalidate` 传播范围 = 工作区级 |
| D7 | 主线锚：`task.py current` 优先；无任务用首条人类指令，确认一次后固定 |
| D8 | 漂移阈值：连续 5 轮无 evidence，或挂起 2h，任一触发 |
| D9 | 同时 open 决策上限 **3 条**（用户选定） |
| D10 | 人类通道 = 插件内（决策清单 + 看板） |
| D11 | 时效承诺 ≤5min（2min 窗口仍在承诺内） |
| D12 | 文档仅内部（本仓 `docs/`，不关联上游 issue） |
| D13 | SQLite = 可重建投影，JSON 为唯一真源 |
| D14 | 双后端自适应（`node:sqlite` / `bun:sqlite`）+ 失败降级纯 JSON（默认采用推荐，复核可推翻） |
| D15 | 全局单库 + **永久保留**（用户选定） |
| D16 | 挂起 `wake_when` 必填 |
| D17 | 24h 未醒 → 自动转 `drifted` |
| D18 | 契约真源 = `contract.json`，DB 只读投影 |
| D19 | 越界 accept 默认拒绝，需 `override{reason,approvedBy}` 并写 audit |
| D20 | 里程碑必须带 evidence 才能点亮 |
| D21 | 进度派生自 `task.json` + git log |

> D9 与 D15 偏离推荐值，已在 design §8 记录代价与缓解。

## 7. 验收（跨子任务）

- [ ] **端到端重放**：用两会话真实消息序列回放，0.9.1 起每轮注入都含 `[mission]` 与 `[todo]`。
- [ ] **漂移可捕获**：构造「连续 6 轮只做协作动作」→ 第 5 轮出现 `[drift]`。
- [ ] **越界被拦**：向 outOfScope 发 accept → 拒绝并给 handoffTo 建议；带 override → 通过且 audit 有记录。
- [ ] **过期快照不放大**：`basedOn` 落后时回复长度 ≤ 原文 30%，且不重述事实。
- [ ] **指标达标**：6 项指标在同一份回放数据上达 §3 目标值。
- [ ] **零回归**：`pnpm build && pnpm typecheck && pnpm test && node scripts/check-skill.mjs` 全绿。
- [ ] **可降级**：删 `collab.db` 后所有工具可用（纯 JSON）；`rebuild` 后数据 100% 一致。
- [ ] **无破坏**：旧 JSON 格式兼容；未升级对端仍可正常收发。

## 8. 风险

| 风险 | 处理 |
|---|---|
| 打包器不认 `node:sqlite` | 动态 import + 运行时探测；GUI 入口不引入；失败降级 JSON |
| 多进程写 DB 锁竞争 | WAL + `busy_timeout=5000` + 单写者队列 + 3 次重试 |
| 契约注入撑爆上下文 | 五段合计 ≤12 行；top3 + 计数 |
| 闸门误伤正常协作 | 只有 outOfScope 命中才拦；scope 为空 = 不拦 |
| 永久保留导致体积膨胀（D15） | 见 design §8：VACUUM + 只索引必要字段 + 可选归档导出 |
| 版本跨度大 | 每版独立可回滚；父任务不做实现 |
