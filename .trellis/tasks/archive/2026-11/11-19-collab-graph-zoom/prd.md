# PRD：关系图缩放 / 拖拽 / 布局重排（0.8.2）

## 问题（用户实测）

- 图**不能缩放**：节点多时字挤在一起；
- **布局混乱**：截图里标签互相压（`定点复核 P2/P3 修…` 压住别的节点）、连线穿过文字。

## 需求

- **R1 缩放**：滚轮 / 触控板双指缩放，范围 0.6×–2.5×；`double-click` 空白处恢复 1×。
- **R2 平移**：按住空白处拖拽（pointerdown/move/up），带边界钳制（不把图拖出视口外面）。
- **R3 布局重排**：画布从 320×180 提到 **640×360**；节点按环分层（中心 1 + 内环 ≤6 + 外环其余），
  标签统一截断到 **8 字** + `…`；最小间距保证任意两节点包围盒不重叠（测试断言）。
- **R4 稳定性**：同一快照两次布局**字节一致**（沿用码位排序）；缩放/平移只影响视图，不改图数据。
- **R5 只读**：缩放/拖拽不写任何状态；不新增依赖（纯 SVG + 指针事件）。
- **R6 TUI 不变**：文本树保持现状。

## 验收

- [ ] 滚轮缩放：`0.6×` / `1×` / `2.5×` 三档的 viewBox 计算正确（纯函数单测）；
- [ ] 拖拽平移有边界钳制，越界后被拉回；
- [ ] 640×360 布局：构造 8 节点，任意两节点包围盒不相交；两次布局一致；
- [ ] 缩放/拖拽后节点点击、折叠仍可用（命中不受 transform 影响或已补偿）；
- [ ] TUI 文本树与既有断言不变；
- [ ] 回归全绿（基线 `899 + 12 + 20 + 36 + 54 + 60 + 47 + 68`），工具数仍 22。

## 非目标

- 不做力导向/自动动画；
- 不做节点拖动改位置（布局是派生的）。
