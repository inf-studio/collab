# 看板滚动复位：稳定 keyed 列表

## 问题

看板（GUI）每 2 秒拉一次快照。用户向下滚动查看长列表时，**每次轮询都会跳回顶部**。
实测环境：`b25-dual-write` 一个工作区就有 25+ 会话（截图），`rstun` 也有十几行。

## 根因（初判）

- `groups()` / `sessions` 每次轮询都返回**全新对象**；
- Solid 的 `<For>` 按**引用**比较，引用一变就重建整棵子树；
- 长列表整块重建 + 宿主容器高度不定 → 滚动位置被浏览器夹回顶部（且造成明显闪烁）。

## 需求

- **R1 稳定身份**：会话行、spawn 行、workspace 组在**成员不变**时复用同一个包装对象（DOM 节点不重建）；
  成员增删时只增删对应节点。
- **R2 字段更新走信号**：行内字段（标题、徽标、契约）变化时只更新内容，不替换节点。
- **R3 滚动保持**：在长列表上滚动后触发一次快照更新（内容变化但成员不变）→ `scrollTop` 与 `scrollHeight` 不变。
- **R4 不回归**：选择/展开/折叠仍是组件内存；`≤640px` 单栏、徽标、决策清单、图槽均不受影响。
- **R5 工具/接口不变**：工具数 29，RPC/快照字段不变。

## 非目标

- 不改轮询间隔（仍 2s）。
- 不引入虚拟滚动（行数在数百级，DOM 复用已足够）。
- 不动 TUI。

## 验收

- [ ] 成员不变时，连续两次快照后**同一行的 DOM 节点是同一对象**（用标记或 WeakSet 断言）；
- [ ] 滚动后更新快照 → `scrollTop` 保持（长列表夹具）；
- [ ] 成员增/删 → 只增/删对应节点，其余节点身份不变；
- [ ] 选择、展开、折叠、徽标、决策清单、窄屏单栏全部回归绿；
- [ ] 工具数 29；回归全绿。

## 变异

1. 把稳定包装退回「每次新建对象」→ 节点身份断言必红；
2. 字段更新改成替换节点 → 同一断言必红。
