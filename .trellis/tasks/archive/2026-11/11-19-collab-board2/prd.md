# PRD：0.8.0 看板主从布局 + 关系图 + 快捷动作

## 背景

0.7.0 的看板是「单栏 + 行内展开」：会话多了要反复展开/折叠；看不到会话/工作区之间的依赖；加急/冻结/归档只能在会话里敲工具。

owner 决定（2026-11-19）：

1. **主从布局**：GUI 左列表 / 右详情；右详情「上图下 items」。TUI 保持树 + 选中行下方 3–5 行详情。
2. **三级关系图**：L0 全局（未选中）/ L1 工作区（选中工作区）/ L2 会话（选中会话为中心，±1 跳 ≤8 节点）。
   GUI 可交互（点选联动、节点折叠、悬停高亮），TUI 文本树。
3. **快捷动作**：加急 / 冻结 / 解冻 / 归档，点击弹确认；服务端复用现有门禁。

## 任务图（顺序即依赖）

| 顺序 | 子任务 | 交付 |
| --- | --- | --- |
| 1 | `board2-layout` | GUI 左右分栏 + 右详情结构（图槽位 / 动作行 / items）；TUI 选中行下方详情 |
| 2 | `board2-graph` | `buildGraph` 三级派生 + GUI 交互小图 + TUI 文本树 |

| 4 | `sender-name` | 入站注入头 `[会话标题][collab:ses_…][kind:thread]`（标题截断 20、缓存 10min） |

## 验收（父）

- [x] 四个子任务各自实现 + 独立复核（layout / sender-name / graph / actions）；
- [x] GUI：左列表选项 → 右侧图与 items 同步；图上点节点 → 左列表与 items 联动；
- [x] 三级图切换正确（未选中=L0，选工作区=L1，选会话=L2），节点上限生效、同一快照两次渲染一致；
- [x] TUI：树 + 选中行详情 + 文本树；窄宽度不崩；
- [x] 四个动作：确认后生效、protected 拒绝、只读 agent 降级、每次写留 audit；
- [x] 回归 `899 + 12 + 20 + 36 + 54 + 60 + 47 + 65` 全绿，工具数仍 22；
- [x] 一次发 `0.8.0`。

## 非目标

- 不做跨机器协作；
- 不做图库依赖（手写 SVG / 文本树）；
- 看板不提供「释放锁」（锁仍归会话自己）。
